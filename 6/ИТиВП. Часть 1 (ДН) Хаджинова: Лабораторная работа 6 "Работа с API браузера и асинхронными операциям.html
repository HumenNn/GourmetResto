Лабораторная работа 6 "Работа с API браузера и асинхронными операциями"

Требуемые условия завершения
Срок сдачи: четверг, 16 апреля 2026, 23:59

1. ЦЕЛЬ РАБОТЫ

Освоение принципов асинхронного программирования в JavaScript, работы с Fetch API, форматами JSON и клиентским хранением данных. Формирование навыков взаимодействия с внешними API и организации локального хранения состояния приложения.

2. НЕОБХОДИМЫЕ ЗНАНИЯ

Для успешного выполнения работы студент должен знать:

    • Основы JavaScript (переменные, функции, объекты, массивы)

    • Работу с DOM и обработку событий (из ЛР №5)

    • Понятие асинхронности и цикл событий в JavaScript

    • Базовые принципы HTTP-запросов

    • Структуры данных JSON (JSON — формат данных, который возвращают большинство API).

    • Основы безопасности веб-приложений

Дополнительно:

  • OAuth 2.0, API-ключи — для работы с API, требующими авторизации (например, Google API).
  • Безопасность на клиенте—  понимание ограничений хранения чувствительных данных

3. ЗАДАЧИ РАБОТЫ

  • Освоить работу с Promise, async/await и Fetch API (REST API и Fetch/Axios для отправки запросов к API).
  • Научиться выполнять HTTP-запросы к внешним API
  • Реализовать обработку данных в формате JSON
  • Организовать клиентское хранение данных с использованием LocalStorage/SessionStorage
  • Реализовать обработку ошибок при асинхронных операциях
  • Интегрировать полученные данные в существующий интерфейс
  • Освоить основы безопасности при работе с API

Шаг 5: Обеспечение безопасности

  1. API-ключи должны быть хранены в .env файле, но следует помнить, что это не защищает от утечек на клиенте.
    • API-ключи в клиентских приложениях всегда будут доступны конечному пользователю, но можно ограничить их использование:
      • Ограничьте использование API-ключей на сервере или используйте ограничения по IP.
      • В случае, если API предоставляет возможность работы с OAuth 2.0, настроить авторизацию через OAuth вместо хранения API-ключа.
  2. В проекте можно также добавить механизм проверки безопасности, например:
    • Использование HTTPS для всех запросов.
    • Ограничение по методу HTTP, например, только GET для публичных данных.

ИНДИВИДУАЛЬНЫЕ ВАРИАНТЫ ЗАДАНИЙ

Задание для всех вариантов:
Реализуйте интеграцию с внешним API согласно вашему типу проекта. Организуйте кэширование данных и синхронизацию между локальным хранилищем и сервером.

1 ПОДГРУППА (Варианты 1-8)

  • Вариант 1 - Новостной портал "NewsHub":

    • Интегрируйте NewsAPI, Guardian API, Currents API для загрузки актуальных новостей

    • Реализуйте кэширование новостей в LocalStorage

    • Добавьте возможность оффлайн-чтения последних загруженных новостей

  • Вариант 2 - Интернет-магазин "TechStore":

    • Используйте FakeStore API для загрузки товаров, Shopify API, Stripe API (для платежей)

    • Реализуйте корзину с сохранением в LocalStorage

    • Добавьте синхронизацию корзины при восстановлении соединения

  • Вариант 3 - Кулинарный блог "TastyBlog":

    • Интегрируйте TheMealDB API для рецептов, Spoonacular API, Edamam API

    • Реализуйте сохранение избранных рецептов

    • Добавьте оффлайн-доступ к избранным рецептам

  • Вариант 4 - Сайт мероприятия "EventSpace":

    • Используйте Eventbrite API, Ticketmaster API, Meetup API

    • Реализуйте кэширование информации о мероприятиях

    • Добавьте оффлайн-просмотр расписания

  • Вариант 5 - Социальная сеть "SocialSphere":

    • Используйте JSONPlaceholder для имитации социальной сети, MockAPI, Firebase Realtime Database

    • Реализуйте черновики постов с автосохранением

    • Добавьте очередь отправки постов при плохом соединении

  • Вариант 6 - FAQ система "HelpDesk":

    • Создайте систему загрузки FAQ с сервера. Используйте Custom JSON API, Airtable API

    • Реализуйте кэширование часто задаваемых вопросов

    • Добавьте оффлайн-поиск по кэшированным вопросам

  • Вариант 7 - Портфолио фотографа "PhotoPortfolio":

    • Интегрируйте Unsplash API для демонстрации работ, Pexels API, Flickr API

    • Реализуйте кэширование галереи для оффлайн-просмотра

    • Добавьте возможность отмечать избранные фото

  • Вариант 8 - Образовательная платформа "EduPlatform":

    • Используйте образовательные API (Khan Academy API, Coursera API, Udemy API)

    • Реализуйте сохранение прогресса обучения

    • Добавьте синхронизацию прогресса при появлении сети

2 ПОДГРУППА (Варианты 9-16)

  • Вариант 9 - Ресторан "GourmetResto":

    • Интегрируйте API для меню и бронирования (Zomato API, Yelp API, OpenTable API)

    • Реализуйте кэширование меню

    • Добавьте оффлайн-просмотр меню и бронирование с последующей синхронизацией

  • Вариант 10 - Библиотека "DigitalLibrary":

    • Используйте API (Google Books API, Open Library API, Goodreads API)

    • Реализуйте кэширование результатов поиска

    • Добавьте оффлайн-библиотеку избранных книг

  • Вариант 11 - Киносайт "MovieHub":

    • Интегрируйте API для информации о фильмах (OMDb API, The Movie Database (TMDb) API)

    • Реализуйте кэширование данных о фильмах

    • Добавьте оффлайн-доступ к избранным фильмам

  • Вариант 12 - Бронирование отелей "HotelBooking":

    • Используйте API (Amadeus API, Booking.com API, Hotels.com API или аналогичный)

    • Реализуйте кэширование доступных отелей

    • Добавьте сохранение истории поиска

  • Вариант 13 - Музыкальный сервис "MusicStream":

    • Интегрируйте API (Spotify Web API, Last.fm API, Deezer API) для информации о музыке

    • Реализуйте кэширование плейлистов

    • Добавьте оффлайн-доступ к избранным трекам

  • Вариант 14 - SaaS платформа "CloudService":

    • Создайте REST API для управления данными. Используйте Custom REST API, Firebase, Supabase

    • Реализуйте оптимистичные обновления интерфейса

    • Добавьте обработку конфликтов при синхронизации

  • Вариант 15 - Спортивный портал "SportArena":

    • Используйте спортивные API (The Sports DB, ESPN API, Football-Data.org)

    • Реализуйте кэширование результатов матчей

    • Добавьте уведомления о новых результатах

  • Вариант 16 - Научный журнал "ScienceJournal":

    • Интегрируйте API (CrossRef API, arXiv API, PubMed API) для научных статей

    • Реализуйте кэширование статей для оффлайн-чтения

    • Добавьте систему закладок с синхронизацией

ПРАКТИЧЕСКИЕ РЕКОМЕНДАЦИИ

  • Всегда обрабатывайте возможные ошибки при работе с API

  • Используйте индикаторы загрузки для улучшения UX

  • Ограничивайте размер данных в LocalStorage (обычно 5-10MB)

  • Регулярно очищайте устаревшие данные из хранилища

  • Тестируйте приложение в условиях плохого соединения

  • Используйте AbortController для отмены запросов при необходимости

  • Реализуйте retry-логику для неудачных запросов
